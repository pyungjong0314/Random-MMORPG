# Luck-Driven RPG (Team 4)  
A 2D pixel art MMORPG where every outcome is determined by luck—dice rolls, coin flips, and random chance dictate your stats, combat, and fate. Step into a world ruled by unpredictability and test your fortune against monsters and other players.  
</br></br></br>

# How to Get Started  
1. Start the server by running `Program.cs` (located in the `server_temp` directory) with port forwarding enabled.  
2. Run the client project on another computer and enjoy real-time multiplayer gameplay.  
</br></br></br>

# Game Communication Overview  
![image](https://github.com/user-attachments/assets/d77bb4c8-f6a0-42d9-bdd3-f86db0939f7b)

The game uses WebSocket-based JSON communication between client and server to handle real-time movement, monster battles, item drops, and PvP.
