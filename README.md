# 운빨존많 RPG (4조)  
주사위, 동전 던지기 등 다양한 랜덤 요소에 따라 능력치와 전투 결과가 결정되는 2D 픽셀 아트 스타일 MMORPG입니다 :) </br>
예측 불가능한 세계에서 운을 시험해보세요!  
</br></br></br>

# 시작 방법  
1. `server_temp` 디렉터리에 있는 `Program.cs`를 실행하여 서버를 시작합니다. (포트 포워딩 필요함)  
2. 클라이언트를 다른 컴퓨터에서 실행하고 멀티플레어 게임을 즐겨보세요!  
</br></br></br>

# 게임 통신 구조  
![image](https://github.com/user-attachments/assets/d77bb4c8-f6a0-42d9-bdd3-f86db0939f7b)

클라이언트와 서버는 WebSocket과 JSON 기반 메시지를 사용하여 실시간 이동, 몬스터 전투, 아이템 드랍, PvP 등을 처리합니다.
